node-fs-read-content

A lightweight, high-performance ESM helper to read multiple files synchronously and map their raw content into structured JSON records.

🚀 Zero Dependencies 📂 Bulk File Reader 📦 ESM Native 🔥 Pure JS

📦 Installation

Install the package into your project using npm or yarn:

npm install node-fs-read-content

Or yarn:

yarn add node-fs-read-content

🛠️ Basic Usage

Import and invoke the default function in your ES Modules:

import readContent from 'node-fs-read-content';

const filesWithContent = readContent({
  filePaths: [
    '/absolute/path/to/file1.js',
    '/absolute/path/to/file2.js'
  ]
});

console.log(filesWithContent);

🛠️ API Signature Reference

The default exported function accepts a single configuration object:

readContent({ filePaths })
Parameter Type Description
filePaths string[] An array of absolute or relative file paths to be read.

Return Value

Returns an array of file records, where each record is shaped as follows:

Array<{
  fileFullPath: string; // The original input path of the file
  fileContent: string;  // The UTF-8 text read from the file
}>
